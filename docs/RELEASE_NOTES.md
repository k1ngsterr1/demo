# Release note — Statement Import 1.0.0, 31.10.2026

Локальная учебная сборка для синтетических выписок. Публикации в магазинах и OTA нет. Фактическая матрица и ограничения: [FINAL_ACCEPTANCE.md](FINAL_ACCEPTANCE.md).

## Изменения

Обычные ошибки фонового восстановления отменённых импортов не показываются на Home и в настройках. Durable очередь восстанавливается при следующем запуске/возврате приложения. Ошибка удаления текущего импорта остаётся видимой; успех по-прежнему возможен только после GET deleted. Убран поясняющий footer настроек. При заполнении очереди остаётся объяснение и повтор, поскольку новый выбор действительно заблокирован.

Заголовки и крупные суммы растут максимум до 125% базового размера. Основной текст и кнопки сохраняют полное системное увеличение. На узком экране логотип переносится между словами, заголовок modal получает всю ширину, крестик остаётся отдельной кнопкой 48 pt. Содержимое и действия прокручиваются. Ограничение display typography — осознанный компромисс; глобального отключения Dynamic Type нет. Исправлен wire Content-Type на iOS: Expo File выводил application/macbinary из расширения .bin. Передача проверенного Uint8Array сохраняет application/octet-stream. Journal, idempotency, timeout, отмена и запрет redirects сохранены.

Android Release использует R8 и shrink resources с точечными правилами Expo reflection. APK содержит arm64-v8a, подписан локальным debug key и предназначен для проверки задания. Mapping приложен. Для магазина нужны собственная release-подпись и отдельная подготовка; публикация по ТЗ не требуется.

## Разрешения и сеть

Android INTERNET нужен для HTTP mock. APK также содержит транзитивный VIBRATE (приложение не вызывает вибрацию) и внутреннее DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION. System picker предоставляет выбранный файл без runtime storage/media permissions. READ/WRITE_EXTERNAL_STORAGE, RECORD_AUDIO и SYSTEM_ALERT_WINDOW заблокированы. На iOS камера, микрофон и фотогалерея не нужны; для LAN возможен Local Network prompt. Android backup отключён. Analytics/crash SDK отсутствуют, network inspector выключен.

Cleartext HTTP / ATS разрешены для локального mock. Клиент принимает loopback или частный LAN IPv4; redirects запрещены. Production потребует HTTPS и более строгой сетевой политики. USB не делает Mac localhost доступным iPhone.

## Копии и очистка

Оригинал у Files/content provider не изменяется. Picker может создать промежуточную копию до JS-проверки размера; приложение очищает свой picker cache и iOS Inbox. Проверка читает блоки до 64 КиБ, не загружая целиком oversized файл. Отправка принятого файла буферизуется в JS, максимум 10 МиБ; native HTTP может иметь дополнительные копии. Это не streaming upload.

Принятая копия: `cache/statement-import/<uuid>.bin`, до отмены или сохранения jobId. При uncertain POST сохраняются ключ и минимальный journal; повторная отправка требует подтверждения. После отмены остаются recovery metadata без документа/имени. AsyncStorage отдельно не шифруется и на iOS может участвовать в backup: использовать только synthetic data.

До POST — «Отменить выбор»; при неопределённой отправке — «Отменить отправку». Клиент освобождает экран и ограниченно проверяет серверное удаление при запуске/возврате на Home. Для job — «Удалить импорт», дождаться GET `deleted`; при 503 повторить. При ошибке локальной очистки повторить очистку. Удаление приложения очищает sandbox, но не сервер; потеря recovery keys не отменяет серверную операцию.

Mock хранит metadata/SHA-256, не исходные байты. `deleted` — контракт учебного API, не гарантия криптографического стирания state-файла.

## Rollout и бинарник

Остановить rollout при втором job на один ключ, откате revision, ложном подтверждении удаления, утечке документа/имени или устойчивом сбое очистки. Для production нужны обезличенные метрики recovery/cleanup failures, duplicate operations и времени подтверждения удаления.

OTA выключен: для раздачи изменений нужна новая автономная сборка. Даже при будущем OTA новый native binary потребуется для Expo/RN, нативных библиотек, config plugins, permissions, Info.plist/AndroidManifest и storage/network policy. R8-настройки также требуют нового бинарника.

## Зависимости инструментов сборки

Legacy glob/minimatch-цепочки удалены совместимыми проверенными заменами. Expo SDK 55 и нативные зависимости сохранены.

Перед публикацией 01.11.2026 полный `npm audit` повторён: **0 vulnerabilities**. Регрессионные тесты настоящих потребителей входят в `npm run check`. Ограничения overrides и процедура сопровождения описаны в [DEPENDENCY_SECURITY.md](DEPENDENCY_SECURITY.md).
